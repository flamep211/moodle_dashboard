# Moodle Analytics Dashboard

Веб-приложение для аналитики данных Moodle с интерактивными графиками и отчетами.

## Описание проекта

Приложение предоставляет комплексный анализ данных студентов Moodle, включая:
- Статистику оценок и успеваемости
- Анализ активности студентов
- Интерактивные графики и диаграммы
- Экспорт отчетов в Excel и PDF
- Ролевая система доступа (преподаватель/администратор)

## Системные требования

- **Python 3.8+** (рекомендуется Python 3.9+)
- **pip** (менеджер пакетов Python)
- **Веб-браузер** (Chrome, Firefox, Safari, Edge)
- **Операционная система**: Windows, Linux, macOS

**Проверка версии Python:**
```bash
python --version  # или python3 --version
```

**Проверка версии pip:**
```bash
pip --version
```

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd moodle_dashboard
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
.\.venv\Scripts\activate  # Windows
# или
source .venv/bin/activate  # Linux/Mac
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

**Основные зависимости:**
- Flask - веб-фреймворк
- SQLAlchemy - работа с базой данных
- pandas - анализ данных
- openpyxl, xlsxwriter - экспорт в Excel
- bcrypt - хеширование паролей
- numpy - математические вычисления

### 4. Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

**Остановка приложения:** Нажмите `Ctrl+C` в терминале

### 5. Вход в систему

**Учетные данные по умолчанию:**
- **Преподаватель:** username: `teacher`, password: `12345`
- **Администратор:** username: `admin`, password: `admin123`

## Структура данных

Приложение работает с SQLite базой данных. Данные можно импортировать из CSV файлов в директории `data/`:
- `students.csv` - данные студентов
- `courses.csv` - данные курсов
- `grades.csv` - оценки студентов
- `logs.csv` - логи активности

### Формат CSV файлов

**students.csv:**
```csv
id,name,group
1,Иванов Иван,Группа А
2,Петрова Мария,Группа Б
```

**courses.csv:**
```csv
course_id,course_name
101,Математика
102,Физика
```

**grades.csv:**
```csv
student_id,course_id,grade
1,101,85
2,101,92
```

**logs.csv:**
```csv
student_id,course_id,action,date
1,101,view,2024-01-15 10:30:00
2,102,submit,2024-01-15 11:45:00
```

## API endpoints

- `GET /` - Главная страница с аналитикой
- `GET /login` - Страница входа
- `POST /login` - Обработка входа
- `GET /logout` - Выход из системы
- `GET /courses` - Список курсов
- `GET /students` - Список студентов
- `GET /analytics` - Детальная аналитика
- `GET /student/<id>` - Профиль студента
- `POST /admin/upload` - Загрузка CSV файлов (админ)
- `GET /export/excel` - Экспорт в Excel
- `GET /export/pdf` - Экспорт в PDF

## Troubleshooting

### Проблема: Приложение не запускается
**Решение:** Убедитесь, что установлены все зависимости:
```bash
pip install -r requirements.txt
```

### Проблема: Ошибка "ModuleNotFoundError"
**Решение:** Активируйте виртуальное окружение перед запуском:
```bash
.\.venv\Scripts\activate  # Windows
source .venv/bin/activate  # Linux/Mac
```

### Проблема: Ошибка при экспорте в Excel
**Возможные причины и решения:**
- **Ошибка "expected str, bytes or os.PathLike object, not NoneType"**: Убедитесь, что установлены обе библиотеки для Excel:
  ```bash
  pip install openpyxl xlsxwriter
  ```
- **Ошибка "DataFrame constructor not properly called"**: Проверьте, что в базе данных есть данные для экспорта
- **Файл не скачивается**: Проверьте права доступа к директории проекта

### Проблема: Данные не загружаются из CSV
**Решение:** 
- Проверьте формат CSV файлов (должны быть в кодировке UTF-8)
- Убедитесь, что директория `data/` существует и доступна для записи
- Проверьте правильность заголовков столбцов в CSV файлах

### Проблема: Не удается войти в систему
**Решение:**
- Используйте учетные данные по умолчанию: `teacher`/`12345` или `admin`/`admin123`
- Если пароли не работают, возможно, они были изменены в коде
- Проверьте, не заблокирована ли учетная запись после нескольких неудачных попыток входа

### Проблема: Графики не отображаются
**Решение:** 
- Убедитесь, что Chart.js загружается корректно (проверьте консоль браузера на ошибки JavaScript)
- Проверьте, что в базе данных есть данные для построения графиков

### Проблема: База данных не создается
**Решение:**
- Убедитесь, что директория `instance/` доступна для записи
- Если файл `moodle.db` поврежден, удалите его - приложение создаст новую базу данных

### Проблема: Приложение работает медленно
**Решение:**
- Убедитесь, что используется виртуальное окружение
- Проверьте объем данных в базе - большие объемы могут замедлить работу
- Перезапустите приложение

### Проблема: Ошибка "Port already in use"
**Решение:** Если порт 5000 занят другим приложением:
```bash
# Найдите процесс, использующий порт 5000
netstat -ano | findstr :5000
# Или запустите на другом порту
python app.py  # и измените порт в коде если нужно
```

### Проблема: Ошибка кодировки при импорте CSV
**Решение:** Сохраните CSV файлы в кодировке UTF-8 без BOM

### Проблема: Не работают стили CSS
**Решение:** 
- Убедитесь, что директория `static/css/` существует
- Проверьте, что файл `style.css` доступен
- Очистите кэш браузера (Ctrl+F5)

## Возможные ошибки при первом запуске

1. **Нет виртуального окружения**: Всегда активируйте `.venv` перед запуском
2. **Не установлены зависимости**: Запустите `pip install -r requirements.txt`
3. **Права доступа**: Убедитесь, что у вас есть права на запись в директорию проекта
4. **Конфликт портов**: Если порт 5000 занят, измените порт в `app.py`
5. **Проблемы с данными**: Если CSV файлы отсутствуют, приложение создаст пустую базу данных

## Проверка работоспособности

После запуска приложения (http://localhost:5000):

1. **Страница входа должна загружаться**
2. **Вход с учетными данными должен работать**
3. **Главная страница должна показывать статистику**
4. **Экспорт в Excel должен скачивать файл**
5. **Загрузка CSV файлов должна работать (для админа)**

Если что-то не работает, проверьте консоль браузера (F12) и логи сервера на ошибки.
